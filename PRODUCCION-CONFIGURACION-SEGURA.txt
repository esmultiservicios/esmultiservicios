ES MULTISERVICIOS — CONFIGURACIÓN SEGURA DE PRODUCCIÓN

1. config/config.php, config/database.php, config/app.key y config/install.lock son archivos locales/runtime.
   NO se incluyen en Git ni deben reemplazarse durante un despliegue.

2. En una instalación nueva usa /install/ para generar config/config.php, app.key e install.lock.

3. En una instalación existente conserva tu configuración de producción actual.
   Si usas el formato legado config/database.php, debe comenzar exactamente con <?php sin BOM, espacios ni líneas anteriores.

4. Este paquete restaura .gitignore para impedir que Git vuelva a versionar credenciales o claves locales.

5. Si esos archivos ya fueron versionados anteriormente, ejecuta localmente:
   git rm --cached config/database.php config/config.php config/app.key config/install.lock
   git add .gitignore
   git commit -m "🔐 Protege configuración local y secretos"
   git push
